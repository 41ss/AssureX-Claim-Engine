# Git in four steps (GitHub Desktop)

Install GitHub Desktop, sign in with **your own** GitHub account, then
File -> Clone repository -> `41ss/AssureX-Claim-Engine`.

1. **Pull** — click *Fetch origin*, then *Pull origin*. Do this every time before you start.
2. **Work** — only inside your own folder.
3. **Commit** — bottom-left box: write what you did ("add date parser for DD/MM/YYYY"), click *Commit to main*.
4. **Push** — click *Push origin*. Push often, at least every hour you work.

## If something goes wrong

- **"Conflict"** — stop. Don't click anything else. Call Victor, Keagan or Cyrus.
- **"Push rejected" / "newer commits on remote"** — click *Pull origin* first, then push again.
- **Committed the wrong file** — don't try to fix it yourself; ask.

## Good commit messages

- yes: `add serial-number mismatch rule`, `fix expiry date off by one day`
- no: `update`, `changes`, `asdf`
